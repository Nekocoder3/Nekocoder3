# Hi, I'm Yaneli 👋

**Senior Backend Engineer** based in Cancún, Mexico. Almost 10 years on the JVM (Java, Groovy, Grails, now Spring Boot), building billing, integrations, and data-heavy systems for multi-tenant B2B SaaS.

## 🔧 What I do

- **Billing and payments:** subscriptions, licensing models, Stripe/OpenPay, Mexican tax invoicing (CFDI 4.0). I fix problems at the root: for example, double charges on split payments, solved in the data model and in the payment integration with idempotency keys.
- **Integrations:** third-party APIs, provider migrations without downtime, retries and rate limits, order sync between platforms.
- **Performance:** I led a slow-query project with a junior engineer. Queries went from minutes to milliseconds through rewrites, indexes, and moving heavy reads to a read replica.
- **Safe change in existing systems:** I led a year-long migration of report exports from a monolith to an asynchronous worker (SQS, EventBridge), one export at a time, with no service interruption.
- **Platform and enablement:** API documentation, mock servers for tests, mentoring junior engineers.
